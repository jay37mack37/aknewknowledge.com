# Maze Runner Online — provenance

Static, serverless build of the multiplayer game `pacman-multiplayer`
(local repository `pacman-multiplayer`, branch `multiplayer`, commit `50479e5912f54ac9cdc1694a46a367081e62352e`),
generated by `node tools/build-static.mjs`. Kanban t_c571eb4d.

- Nothing runs on our machines. The first player in a room hosts the same
  authoritative simulation (`src/room_service.js`) in their browser; others connect
  to that host over WebRTC data channels.
- Signaling (offer/answer exchange only) goes through public Nostr relays via
  trystero 0.26.0 (MIT, `vendor/LICENSE-trystero.txt`), bundled to `vendor/trystero.js`.
  No accounts, keys or secrets exist in this build.
- Hardening: 4 KB guest message cap, 32 KB receive cap, per-peer token bucket with a
  60 s kick ban, max 8 peers / 4 players, settled-host anti-hijack, strict CSP
  (`script-src 'self'`, `connect-src 'self' wss:`).
- Three.js r174, MIT licence (`vendor/LICENSE-three.txt`).
